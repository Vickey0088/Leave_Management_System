🏢 Leave Management System
📌 Project Overview

The Leave Management System is a web-based application built using ASP.NET Core MVC that helps organizations manage employee leave requests efficiently. The system supports three main roles: Employee, Manager, and Admin, each with different responsibilities and access permissions.

Employees can apply for leave, managers can review and approve requests, and administrators can manage the entire system. The application is built using C#, Entity Framework Core, Repository Pattern, and Microsoft SQL Server, following a clean and scalable architecture. 🚀

🛠️ Technologies Used
💻 ASP.NET Core MVC
⚙️ C#
🗄️ Microsoft SQL Server (MSSQL)
🔗 Entity Framework Core
📦 Repository Pattern
🔍 LINQ
🎨 Bootstrap
📄 Razor Views
👥 User Roles
👨‍💼 Employee

Employees can manage their leave requests:

📝 Apply for leave
📅 Select leave dates and leave type
📊 View leave history
🔍 Track leave status (Pending / Approved / Rejected)
👨‍💻 Manager

Managers are responsible for reviewing employee leave requests:

👀 View team leave requests
✔️ Approve leave requests
❌ Reject leave requests
📊 Monitor employee leave records
👑 Admin

Admins manage the entire system:

👥 Manage employees and managers
📋 View all leave requests
⚙️ Manage leave policies
🗄️ Perform CRUD operations on system data
✨ Features
🔐 Role-Based Access Control (Employee, Manager, Admin)
📝 Leave Application System
✔️ Leave Approval / Rejection Workflow
📊 Leave History Tracking
🗄️ Database Management with Entity Framework Core
⚡ Clean Architecture using Repository Pattern
🔄 CRUD Operations

The system supports full CRUD functionality:

➕ Create employee and leave records
📖 Read employee and leave information
✏️ Update leave requests or employee details
❌ Delete records when required
🏗️ Project Architecture

The project follows a layered architecture:

Controllers
   ↓
Repositories
   ↓
Entity Framework Core
   ↓
SQL Server Database
🎯 Controllers handle application logic and user requests
📦 Repositories manage database operations
🔗 Entity Framework Core acts as ORM
🗄️ SQL Server stores employee and leave data
🗄️ Database Integration

The system uses Microsoft SQL Server with Entity Framework Core for:

📊 ORM-based database operations
🔄 Database migrations
⚡ Efficient data retrieval using LINQ
